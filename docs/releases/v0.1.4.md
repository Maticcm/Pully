Pully 0.1.4 fixes Spotify downloads and makes download progress steadier and easier to follow.

**Status:** pre-release. Spotify support remains experimental and depends on the installed SpotiFLAC provider and its services.

### Fixes

- Spotify reports are recognized even when SpotiFLAC writes diagnostic logs before or after the JSON report.
- Quick mode automatically uses Original FLAC output for Spotify when the audio preset requests an unsupported format.
- Spotify artist and duration metadata work with reordered HTML attributes, single quotes, and whitespace around attribute values. HTTP error pages are ignored.
- Video and audio streams share one progress bar. The current stream is labeled, and 100% is reserved for the completed download after processing.
- Speed and remaining-time estimates use a smoothed rate, a short warm-up, and at most one estimate update per second. ETA is hidden when the total size is unknown. Playlist progress identifies the current item.
- Percentage text no longer fades in on every percentage change.
- Spotify file replacement is staged on the destination drive before publishing. Failed replacements preserve the previous file; Skip mode cannot overwrite a file created concurrently.
- Ordinary yt-dlp and Spotify downloads now use the Windows process cleanup guard, stopping helper processes if Pully exits or crashes.

### Downloads

- **`Pully_0.1.4_x64-setup.exe`**: Windows installer, recommended for most users.
- **`Pully_0.1.4_x64_en-US.msi`**: Windows MSI installer.
- **`Pully_0.1.4_x64-standalone.zip`**: Extract the whole archive and run `pully.exe`.
- **`Pully-browser-extension-1.0.0.zip`**: Optional browser extension.
- **`latest.json`**, the installer **`.sig`**, and **`SHA256SUMS.txt`**: update metadata and download checksums.

### Verification and limitations

Verified with Rust regression tests, frontend typechecking/build/lint, quick-mode format tests, and a local HTTP download through the bundled yt-dlp that downloaded and merged separate video and audio streams. A live Spotify provider download has not been verified for this release. Estimates cover the media transfer; merging, conversion, and metadata processing can take additional time.

Version 0.1.1 and newer can install this signed update when Pully is idle. Check manually in Settings → Status.
