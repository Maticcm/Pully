Pully 0.1.2 fixes the brief unresponsive period when opening the app. Local-first Windows media downloader built on Tauri 2, yt-dlp, and FFmpeg — no accounts, no telemetry, no ads.

**Status:** pre-release. Core downloading (video/audio, playlists, Quick Mode, metadata/thumbnails/subtitles) is implemented and tested; Spotify support is beta/experimental; the browser extension is functional but not yet on the Chrome Web Store.

## What's changed

- Tool version and capability checks run on background workers instead of blocking the window when Pully starts.
- Browser host registration and launch-path recording also run in the background, after the app's state is ready.
- The dependency lock is released before running tools, allowing other actions to proceed while checks finish. Tool checks after installing dependencies use the same background path.

## Downloads

- **`Pully_0.1.2_x64-setup.exe`** — recommended installer (NSIS). Self-contained: bundles yt-dlp, FFmpeg, and the Deno JS runtime yt-dlp needs for YouTube, so no separate download tools are needed.
- **`Pully_0.1.2_x64_en-US.msi`** — alternative MSI installer, same bundled contents.
- **`Pully_0.1.2_x64-standalone.zip`** — standalone app with the same bundled tools and licenses. Extract the entire ZIP and run `pully.exe`; keep the `binaries` folder beside it. Requires Windows WebView2. Settings are stored in app data. Automatic updates use the NSIS installer; disable them if you prefer replacing the standalone folder manually.
- **`Pully-browser-extension-1.0.0.zip`** — optional Chromium extension (Chrome/Brave/Edge) for tab detection. Not on the Web Store yet — load it unpacked: `chrome://extensions` → enable Developer mode → *Load unpacked* → select the extracted folder. See [docs/BROWSER_INTEGRATION.md](https://github.com/Maticcm/Pully/blob/main/docs/BROWSER_INTEGRATION.md) for setup and permissions.
- **`Pully_0.1.2_x64-setup.exe.sig`** and **`latest.json`** — installer signature and update manifest used by Pully's updater.
- **`SHA256SUMS.txt`** — checksums for all six files above.
