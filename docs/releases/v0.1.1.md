Pully's second public release improves the Windows download workflow and adds signed app updates. Local-first Windows media downloader built on Tauri 2, yt-dlp, and FFmpeg — no accounts, no telemetry, no ads.

**Status:** pre-release. Core downloading (video/audio, playlists, Quick Mode, metadata/thumbnails/subtitles) is implemented and tested; Spotify support is beta/experimental; the browser extension is functional but not yet on the Chrome Web Store.

## What's changed

- Smoother opening and closing of the Advanced options dropdown.
- YouTube downloads prefer HTTPS formats, and output paths no longer trigger the ignored `--paths` warning.
- Thumbnail embedding is skipped for formats that do not support it, preventing avoidable playlist failures. Internal progress markers are hidden from technical errors.
- Install or update the optional SpotiFLAC integration from **Settings → Status**. Requires Python 3 and uses an isolated environment in Pully's app data folder.
- The Windows app and native browser host use the GUI subsystem; helper tools run without opening console windows.
- Paste uses the native clipboard API, avoiding the WebView clipboard permission popup.
- Signed app updates check on startup and daily, then install automatically once downloads and other work are idle. Disable this in **Settings → Status**, or check manually there.

## Downloads

- **`Pully_0.1.1_x64-setup.exe`** — recommended installer (NSIS). Self-contained: bundles yt-dlp, FFmpeg, and the Deno JS runtime yt-dlp needs for YouTube, so no separate download tools are needed.
- **`Pully_0.1.1_x64_en-US.msi`** — alternative MSI installer, same bundled contents.
- **`Pully_0.1.1_x64-standalone.zip`** — standalone app with the same bundled tools and licenses. Extract the entire ZIP and run `pully.exe`; keep the `binaries` folder beside it. Requires Windows WebView2. Settings are stored in app data. Automatic updates use the NSIS installer; disable them if you prefer replacing the standalone folder manually.
- **`Pully-browser-extension-1.0.0.zip`** — optional Chromium extension (Chrome/Brave/Edge) for tab detection. Not on the Web Store yet — load it unpacked: `chrome://extensions` → enable Developer mode → *Load unpacked* → select the extracted folder. See [docs/BROWSER_INTEGRATION.md](https://github.com/Maticcm/Pully/blob/main/docs/BROWSER_INTEGRATION.md) for setup and permissions.
- **`Pully_0.1.1_x64-setup.exe.sig`** and **`latest.json`** — installer signature and update manifest used by Pully's updater.
- **`SHA256SUMS.txt`** — checksums for all six files above.
